# 首发范围

当前为可运行的独立重建测试版，尚未完成全部设备验收。复用已核验的锤击和遗物实现，重写最小会话与界面绑定，保留明亮工坊风格和已完成剑素材。原工程和旧存档独立保留。用户已选择先使用Google官方测试广告完成本版。

## 保留的闭环

- 五结果概率、价值、保护顺序、充能与入神、99终值；保留原遗物效果和合法获取条件。
- 有限供剑、库存、主订单、金币与剑信用、随机遗物报价、商人及原道具。
- 原成就、遗物开池、剑种发现与解锁；页面可合并，规则不删除。
- 失败免费重开、21单完成与延期、退出续玩。
- 高频页面仅锻造、订单、剑柜、遗物、商人；赠礼、替换、交单和终局使用必要弹窗。

## 两个独立广告接点

| 接点 | 奖励与上限 | 持久范围 |
| --- | --- | --- |
| `relic-slot-unlock` | 遗物总上限8格，初始2格；第3至8格逐个earned解锁，每次只开下一格，最多6次成功 | `Profile.UnlockedRelicSlots`，跨契约和重启保留 |
| `prestrike-ward-grant` | 商人到访安全页自愿领取既有龙鳞`ward`×1，每契约最多成功一次 | `Run.RewardedWardGranted`，新契约重置 |

槽位解锁不送遗物或货币；当前容量满时仍可合法购买并显式替换，不强制广告。界面沿用2×4格，初始2开6锁。龙鳞进原道具库存，玩家在合法锤前手动使用，不自动武装，不改商人库存、购买计数或价格档。

两接点分别去重与计数。显示、关闭和无填充不是earned；奖励与凭据消费必须同次成功保存。当前永久权益指同一本地档案跨局/重启，不承诺卸载或换机恢复。

## 不带入首发

不带旧XP、等级、天赋、额外信用副单、基础保底货架、预约、作品成长、多重恢复预算、新货币、体力、战斗或第9格。不搭建通用动态规则或奖励平台。

新局没有碎后广告复活。真实死亡仍通过待损失事件和一次权威结算提交；成功后只显示结果与继续。

原版回溯/撤销目前缺完整实现，本次明确暂缓。碎后恢复不能替代原回溯，不宣称100% Steam功能或二进制一致。

概率向量通过不等于全部遗物生命周期、整局平衡或生产广告通过。初始2槽和免费龙鳞改变实际强度，需独立验证；内部保留8槽全开对照，不能直接套用旧版本胜率。
