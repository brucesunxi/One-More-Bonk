## 三张参考图的用法

用户提供的三张图是 ForgeTax 工具站的深色导航菜单：指南分类、遗物分类、工具入口。它们没有展示游戏锻造主场景。可吸收的是图标、名称、一句说明的阅读顺序，分组、选中强调和次级入口收纳。工具站的计算器、日历、价格查询不需要变成首发游戏的独立页面。

本项目沿用已确认的明亮工坊：薄荷控台、象牙石砧、暖金主按钮、藏蓝文字和庭院背景。三张参考图及其原游戏图标均未复制进仓库。原规则目录的名称、数字与效果说明由 Session/规则数据提供；不从截图 OCR 拼出另一套数据。

真实碎裂先由Session保存待损失事件；弹窗通过`TryAcceptBreak(eventId)`让会话一次吸收后置状态与遗物副产物并保存。保存失败保留待处理状态，动画或结果展示不另外结算。没有碎后广告复活。原回溯暂缺是首发功能差异，不用恢复券图标伪装实现。

## 两组数字必须分清

充能控台的十个孔只表示 0..10 充能/入神准备，不是遗物槽。已迁入的 `dock-slots.json` 仅描述这十孔坐标。遗物架另用 2×4 布局，账号初始开 2 格，硬上限 8 格。

第 3..8 槽逐格自愿广告解锁；成功后同一本地档案跨契约/重启永久保留，最多六次成功解锁。锁格预览写清“永久解锁第 N 格”，不写成临时增益或自动送遗物。只有下一锁格可发请求，其他锁格显示顺序。广告未填充/关闭/取消不发奖、不补免费槽，既有可用格仍可继续玩；不承诺初始 2 格的完整通关能力或卸载/换机恢复。

槽位 earned 由奖励/Session 边界处理。UI展示会话中的待奖励请求与已保存权益，不自行造requestId或执行`UnlockedRelicSlots++`。成功开格即时显示新容量，不自动装备遗物，也不删除现有装备。请求中屏蔽重复启动；写入失败可通过广告适配器重试同一已earned回执，不要求重看。该描述是已实施的调用边界，不是本轮手机广告成功证据。

商人龙鳞是另一独立预算：一次完整契约/Run 最多成功领一次，不随当天订单重置，不占永久槽位的六次计数。领取只增加既有 ward 库存，不改金币/剑信用、商品库存、价格档、剑、票数或 RNG，也不自动武装。已持有龙鳞可正常叠加，不另设库存空门槛。入神/满充能时的武装限制、任意一次合法锤击消耗已武装龙鳞等语义由 Session 给出；UI 不根据动画是否碎裂决定消耗。

所有广告前、后台切换与弹层都暂停锻造钟，返回时需要新的主动按压。两个广告入口文案与计数分开，不展示通用“复活次数”。显示/关闭回调不等于 earned。

## 纹理、图集与字体接法

这些 PNG 的原导入类型为普通 `Texture2D`，不是已经配置好 border 的 Sprite。按钮/面板的九宫格来自 `asset-layout.json`，不能只挂一个默认 `Image` 就声称完成九宫格。源坐标原点在左上：`uv=(x/sw, 1-(y+h)/sh, w/sw, h/sh)`。源图可能被导入器等比或非等比重采样，仍按源 `sw/sh` 归一化；若创建 Sprite，先以实际纹理宽高分别缩放源 rect 与 border，再转 Unity 左下原点。`left/top/right/bottom` 是源切边，`dl/dt/dr/db` 是旧界面的目标逻辑切边，不能混用。

保持 alpha、Clamp/Bilinear 和原导入设置。已肉眼检查全部 10 张源 PNG；按钮/面板外缘有透明留白，按裁切记录取有效范围，不铺黑底。庭院只作背景，文字盖有稳定面板；应按屏幕比例裁庭院，不拉伸剑、砧台或圆形锤底图。手机安全区/窄长屏允许内容区滚动，底部导航与主动作不压系统手势区，触摸目标至少 44dp；不能照搬工具站的小菜单行高。

道具图集是1254×1254、4×4均分，单格名义尺寸313.5；新加载器用归一化UV，不截断成313造成逐列漂移。可复用索引为金币tile9、剑信用tile14、ward tile10、starshard tile11、普通供剑tile12；当前新UI实际调用龙鳞tile10，其余为可复用映射，不声称16格均已在手机显示。tile13的旧恢复卷轴及其它旧玩法图样不表示首发存在该道具。94遗物用全名/说明与详情呈现，不搬工具站图标补齐。

字体原文件大小约16.4MB，已在手机显示中文并保留完整许可。实际字图集内存、包体优化与长文换行仍需量测；尚未做子集化或宣称内存优化完成。长遗物名、极大价值、窄屏触摸目标/安全区及全部详情文本需要后续手机QA。

## 剑外观闭包

两个生成器只依赖 `System`、集合、`UnityEngine` 与 `UnityEngine.Rendering`，没有 Session/Career/RiskWorkshop、磁盘、SDK 或游戏 RNG 依赖。普通剑生成器自建确定性 128px 表面纹理，商人剑自建几何/材质。没有复制缩略图相机、旧 viewer、旧动画业务或武器物理脚本。

普通外观提供12阶，生成器名义标签为`0,2,4,9,15,22,29,45,60,75,90,99`；这些标签不作为规则升级阈值。新viewer从Snapshot及`Stage/MaterialAwakened`等只读内核函数取得外观参数，不用外观反推等级或添加路线奖励。商人生成器支持`world-tree`、`fishblade`、`funerary`。手机已观察当前剑预览，全部12阶、材质变体与三种商人剑仍需逐项验证；不代表所有规划美术系列已经完成。

几何API为`RageWeaponGeometry.Create(stage, materialRoute, awakened)`和`MerchantWeaponGeometry.Create(family, stage, route, awakened)`，各自有`Release`。两者坐标X为握柄至剑尖、XY轮廓、Z厚度，有`GripSocket`、`DisplayPivot`、`ForgeContact`。新viewer已缓存外观键，变化时重建并释放旧生成网格，不在每次repaint生成；共享材质不会随单把剑释放。

动态材质用`Shader.Find("Universal Render Pipeline/Lit")`，以Standard为备用。新项目包固定URP17.3.0；保留材质引用包内Lit GUID `933532a4fcc9baf4fa0491de14d08ed7`和Editor AssetVersion GUID `d0353a89b1f911e48b9e16bdc9f2e058`，其它贴图为内嵌，无旧工程纹理依赖。当前玩家包已在手机显示3D剑，说明这一已观察路径可用；不能据此保证全部材质关键字、形态、光照与设备组合均已验证。

## 已实施的 Session 与广告边界

入口组件为`OneMoreBonk.Rebuild.Presentation.RebuildWorkshop`，由四个Presentation partial实现；自建屏幕相机、隔离剑预览相机/RenderTexture和IMGUI五页。UI按需缓存`Snapshot()`深拷贝，命令后和计时刷新时更新，不为每个控件重复复制，也不建立影子业务状态。

- 快照显示订单/愤怒/目标、金币/剑信用、当前持有剑与选择/封存/交付标记、遗物报价与装备、已开槽数、道具库存/武装、商人、待损失/结局及图鉴/成就。
- 锻造页通过`GetProbabilities`显示原始五结果抽签票；龙鳞另标“本锤防碎已武装”，不会把Break票直接改为0。等级/价值/充能/入神由快照与只读函数取得。
- 玩家动作调用`TryStart/TrySelect/TrySetLocked/TryMarkForOrder/TryStrike/TryAcceptBreak/TrySellForCredit/TryBuyRelic/TryDiscardRelic/TryReroll/TryBuyMerchant/TryUseConsumable/TrySubmitOrder/TryContinueExtended/TryEndContract`，不直接改列表、余额、预算或RNG。
- 广告桥暴露`RewardRequested/RewardRetryRequested/RewardCancelRequested`、`SetRewardPresentation`和`RefreshFromSession`，earned仍进入奖励/Session幂等入口。未就绪时不点击即发奖；SDK测试接法与验证边界见[广告记录](Ads/official-test-integration.md)。
- 离开锻造或打开阻塞弹层先checkpoint，失焦/后台亦保存；切页、松手、弹层、失焦、广告均清长按。返回首帧不补后台dt。保存失败保留重试入口，动画不提交经济。
