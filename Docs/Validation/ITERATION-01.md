验收包使用独立`com.brucesunxi.onemorebonk.acceptance`应用和存档，不安装覆盖`.rebuild`。测试凭据、可改夹具与入口均在`UNITY_EDITOR || BONK_DEVICE_ACCEPTANCE`条件内；额外符号只传给本次验收构建。普通Player符号的单文件编译检查也未包含验收类/测试凭据标记。此检查不是正式Release产物扫描。

验收构建固定IL2CPP/ARM64，前后比对规则和逻辑源码哈希，完成后还原原试玩项目设置、场景与依赖解析缓存。本轮修复了构建器在空初始场景下恢复失败的问题；最终批处理退出码为0，正常包名、版本5及解析设置与基线一致。报告导出后已卸载临时验收应用，手机返回原试玩包。

## 复演

离线检查沿用：

```sh
UNITY_EDITOR_ROOT="<Unity.app完整路径>" sh Tools/verify-session.sh
UNITY_EDITOR_ROOT="<Unity.app完整路径>" sh Tools/verify-ads-adapter.sh
```

Unity菜单`One More Bonk Rebuild/Acceptance`可运行原生编辑器套件或构建独立Android验收包。批处理入口为`OneMoreBonk.Rebuild.Editor.RebuildAcceptanceBuild.BuildAndroid`。输出保存在已忽略的`Builds/Android/Acceptance/`；设备运行后导出其`files/controlled-acceptance/acceptance-report.json`。不要将这个包发给普通试玩参与者。
