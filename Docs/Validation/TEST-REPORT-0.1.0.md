## 版本5实际使用与新契约证据

以下由构建负责人在最终安装包及保存状态确认：

- 更新运行后保留3槽、2条奖励提交、龙鳞库存1，剑未武装。
- 手动武装后库存为0、`WardArmed=true`，累计锤击仍为3；武装没有额外触发锤击。
- 下一次140ms单击产生1次Hold，累计锤击变4、等级为2、`WardArmed=false`；槽位仍3、奖励提交仍2。此例证明下一锤消费待用效果，不等于实际演示了一次Break被龙鳞保护；保护顺序另有受控回归。
- 菜单结束旧测试契约，再免费开始新契约并进入赠礼。保存断言通过：新RunId不同、供剑3把、槽位仍3、`RewardedWardGranted=false`、无待处理奖励请求、奖励提交仍2。

## 已知限制

- 原版完整rewind延期；物理交接简化为直接入剑柜，广告槽位及契约龙鳞也是明确手游差异，不称完全复刻。
- 仅接入Google官方测试广告；正式AdMob广告位、收入验证及SSV未接入，未验mediation或iOS。
- 权益属于独立本地Profile；跨设备账号、云权益及卸载恢复未实现。
- earned未落盘时的免重看重试依赖当前进程内存；其间进程被杀，不承诺冷启动恢复这份奖励证据。损坏主档回退备份可能回退最近一次提交。
- 未在手机完整完成21单，也未逐次播放6条槽位广告开到8。全槽上限、重复/无填充等规则由受控测试覆盖；两种有限策略探针的自然失败和21单完成是独立离线证据，不转算手机完成或真实玩家胜率。
- 所有页面、广告早退/后台阶段、故障恢复、性能及设备兼容尚未形成完整真机矩阵；留存、广告接受度及生产平衡未验证。

冻结结论：版本5可作为独立最小测试版试玩；已验证的广告、存档与核心使用链路具备明确版本证据，生产发布与全面平衡仍需后续验收。
